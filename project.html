부분일치 검색 성능 개선
문제 인식
17만 건 게임 카탈로그에서 LIKE 부분일치 검색 p95가 3,034.1ms까지 증가했습니다.
문제 해결
실행 계획과 동일 fixture를 대조하고 pg_trgm GIN 인덱스 및 짧은 검색어용 bigram 인덱스를 적용했습니다.
측정 결과
문제 인식
p95 9.7ms, p99 10.8ms, HTTP 실패율 0%를 확인했습니다.
문제 해결
Dense·Sparse 하이브리드 검색과 deadline 초과 sparse 조회 취소 흐름도 회귀 테스트로 검증했습니다.
