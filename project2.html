AI Usage Banner
AI Usage Banner는 Codex와 Claude 여러 계정의 사용량을 보여주는 macOS 메뉴바 앱입니다. 계정 분리, 테마 선택, 마지막 정상 데이터의 로컬 보관을 지원합니다.
개인 프로젝트
1인
설계·개발
GitHub Repository
Swift, SwiftUI, AppKit
macOS 13+, Swift 5.9+
Codex·Claude 계정 분리
외부 런타임 의존성 없음
다중 계정 관리
Codex와 Claude 계정을 원하는 만큼 등록할 수 있는 프로필 구조
서비스별 프로필을 분리해 계정별 사용량을 섞지 않고 표시.
메뉴바에 표시할 계정과 순서를 직접 선택.
메인 계정 카드의 드래그앤드롭 순서를 메뉴바 순서에 반영.
설정 화면에서 계정 이름 변경·제거와 메뉴바 표시 ON/OFF 지원.
계정 프로필에는 표시 이름·예상 플랜·로컬 설정 경로만 저장.
인증 토큰이나 이메일은 config.json에 저장하지 않음.
macOS 메뉴바 UX
SwiftUI와 AppKit으로 팝오버와 메뉴바 화면을 구현.
Dual Battery, Minimal Text, Compact Batteries 세 테마 제공.
Compact Batteries 크기를 105~200% 범위에서 조절.
한국어·영어 시스템 언어와 5시간·주간 잔여량 표시 지원.
최소 1개부터 등록된 계정 수만큼 메뉴바에 표시.
로컬 우선 장애 대응
문제 인식
네트워크 오류가 발생하면 사용량 화면이 비어 사용자 판단이 어려울 수 있었습니다.
문제 해결
마지막 정상 데이터를 로컬에 보관해 일시적인 오류에도 캐시된 사용량을 구분해 표시합니다.
개인정보 보호
문제 인식
대화 내용·프롬프트·프로젝트 파일을 읽거나 별도 분석 서버로 전송하지 않아야 했습니다.
문제 해결
서비스별 저장 위치에서 인증 정보를 읽고, 토큰을 복사·삭제하거나 별도 저장하지 않습니다.
